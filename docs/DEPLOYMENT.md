# Инструкция по развертыванию ShadowStar на сервере

Данное руководство описывает установку, настройку и управление сервером **ShadowStar** на любом VPS (Ubuntu, Debian, CentOS, AlmaLinux, Rocky Linux).

---

## 1. Быстрая установка в 1 команду

Подключитесь к вашему серверу по SSH и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/shadowstar/shadowstar/main/scripts/install.sh -o install.sh && sudo bash install.sh
```

*(или, если репозиторий уже скопирован на сервер)*:

```bash
cd ShadowStar/scripts
sudo bash install.sh
```

### Что делает скрипт автоматически:
1. Определяет архитектуру сервера (`x86_64` или `ARM64`).
2. Устанавливает необходимые утилиты (`curl`, `openssl`, `qrencode`, `ufw`).
3. Генерирует криптографически стойкий 32-байтный мастер-ключ.
4. Настраивает оптимизацию ядра Linux для проксирования:
   - Включает алгоритм контроля перегрузок **BBR** (`tcp_bbr`);
   - Увеличивает лимиты открытых файлов (`LimitNOFILE=1048576`);
   - Тюнит буферы сокетов TCP для максимальной скорости.
5. Создает и запускает службу **Systemd** (`shadowstar.service`) с автозапуском при перезагрузке сервера.
6. Открывает порт в файрволе (UFW / Firewalld).
7. Выводит готовую конфигурацию, **ссылку `shadowstar://...`** и **QR-код в терминале**!

---

## 2. Управление сервером

После установки доступна удобная глобальная команда `shadowstar`:

| Команда | Описание |
| :--- | :--- |
| `shadowstar status` | Проверить статус службы и потребление ресурсов |
| `shadowstar restart` | Перезапустить прокси-сервер |
| `shadowstar stop` | Остановить прокси-сервер |
| `shadowstar start` | Запустить прокси-сервер |
| `shadowstar logs` | Просмотр журнала событий в реальном времени |
| `shadowstar link` | Показать ссылку подключения `shadowstar://` и QR-код |
| `shadowstar update` | Безопасное обновление до последней версии (Zero-Downtime) |

---

## 3. Автоматическое обновление

Для обновления сервера до актуальной версии достаточно запустить:

```bash
sudo shadowstar update
```

Скрипт обновления:
1. Создает резервную копию текущего бинарного файла (`shadowstar-server.bak`).
2. Проверяет целостность нового исполняемого файла перед заменой.
3. Перезапускает службу `shadowstar.service` без потери настроек.
4. В случае сбоя мгновенно выполняет автоматический откат к рабочей версии.

---

## 4. Конфигурационный файл

Файл конфигурации расположен по пути: `/etc/shadowstar/config.json`:

```json
{
  "listen_addr": ":443",
  "master_key": "YOUR_32_BYTE_HEX_MASTER_KEY",
  "fallback_target": "www.microsoft.com:443",
  "sni": "www.microsoft.com",
  "verbose": false
}
```

- `listen_addr`: Порт прослушивания (рекомендуется `443`, так как он никогда не вызывает подозрений у провайдера).
- `master_key`: 64-символьная hex-строка (32 байта) общего ключа аутентификации.
- `fallback_target`: Адрес сайта-приманки, куда перенаправляются все сканеры и зонды цензоров.
- `sni`: Имя домена, маскирующего трафик.
